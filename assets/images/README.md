# Imagens do site

Pasta destinada às imagens gerais da interface do site.

## Fundo da página inicial

Envie a imagem principal da home para esta pasta com o nome:

`home-background.png`

Caminho final esperado:

`assets/images/home-background.png`

As imagens específicas de cada livro permanecem dentro da pasta `livros/<livro>/imagens/`.
